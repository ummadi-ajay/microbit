# Micro:bit flipbook

A flipbook viewer with zoom and on-screen instructions for a micro:bit guide from MakerWorks Lab. The pages are images in `flipbook_pages/`.

**Live:** https://makerworkslab.in/microbit/

The full book, *Getting Started with Micro:bit*, is on the [portfolio](https://makerworkslab.in/ajayummadi/projects/microbit-beginners-guide/).

Built by [Ajay Ummadi](https://makerworkslab.in/ajayummadi/) at [MakerWorks Lab](https://makerworkslab.in/), Mumbai.
